# Процесс проверки перед выпуском

Правило простое: **правка не уезжает в репозиторий, пока `node test/run.mjs` не даст зелёный прогон.**

```
npm test          # то же самое
node test/run.mjs # 54 проверки, ~6 секунд
```

## Почему фикстуры, а не живой сайт

Из облачной песочницы, где я работаю, `rbc.ru` отдаёт 401 — сеть закрыта.
Поэтому проверки идут против фикстур `fixture-article.html` и
`fixture-feed.html`. Это не выдуманная разметка: все имена классов сняты с
живых страниц через мост к браузеру. Фикстура фиксирует мои допущения о
вёрстке РБК — если сайт переименует класс, тесты останутся зелёными, а на
живой странице сломается.

Отсюда второй слой: **сверка селекторов с живым сайтом** (`selectors.md`).
Её надо прогонять при каждой правке, которая опирается на новый селектор,
и раз в пару недель просто так.

## Что именно проверяется

Каждая проверка появилась из настоящей поломки, а не из головы.

| Проверка | Какой баг ловит |
|---|---|
| не удаляет узлы сайта из DOM | белый экран: удаление узлов из-под React ломает согласование дерева |
| нет бури мутаций при прокрутке | моргание: наблюдатель удаляет — React возвращает — наблюдатель удаляет |
| нет необработанных исключений | падение инициализации на ReferenceError в мёртвой зоне |
| поздняя инъекция | тот же ReferenceError, воспроизводится подменой `readyState` на `complete` |
| прогресс: старт, монотонность, 100%, плавность | полоса стояла в нуле первые экраны и прыгала 0 → 100 на скрытом абзаце |
| режим страницы на статье / ленте / SPA-переходах | статья открывалась в вёрстке ленты и наоборот |
| контраст в тёмной теме ≥ 4.5:1 | чёрное на чёрном в блоке «Персоны» |
| Pro скрыт, обычные новости целы, ссылка в шапке цела | чтобы чистка не вырезала лишнего |

## Как устроен страж (`guard.js`)

Внедряется до юзерскрипта и делает три вещи:

1. **Считает удаления чужих узлов.** Наши элементы помечены префиксом `tm-`,
   всё остальное принадлежит сайту. Любое удаление — провал.
2. **Изображает React.** Удалённый чужой узел возвращается на место через
   тик. Скрипт, который удаляет вместо того чтобы прятать, немедленно
   сорвётся в цикл, и это видно в счётчике мутаций.
3. **Ловит ошибки** — `error`, `unhandledrejection`, консоль.

Сетевые ошибки загрузки шрифтов из отчёта отфильтрованы: в песочнице нет
сети, и это не дефект скрипта.

## Чего эти тесты НЕ покрывают

Честный список, чтобы не было ложного спокойствия:

- настоящий React РБК — фикстуры статичные, реальное поведение при
  гидрации и подгрузке ленты проверяется только вживую;
- реальные рекламные сети — блокировка запросов проверяется по коду, а не
  по факту отсутствия баннера;
- визуальная составляющая — что «красиво» и «читаемо», тест не знает;
- поведение на других разрешениях и в других браузерах.

Поэтому после зелёного прогона остаётся ручной прогон по живому сайту:
статья прямым заходом, статья переходом из ленты, главная, рубрика,
светлая и тёмная тема, прокрутка до конца статьи.
